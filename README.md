# カツオ一本釣り

船を走らせるだけ。釣りは全自動。3分でカツオを何本獲れるかを競うスコアアタック型ローグライト。

**▶ 遊ぶ: https://teitasan.github.io/katsuo-ippon/**

## 遊び方

- **マウスを動かした方向へ船が進む。** クリック不要、キーボード不要。カーソルは目的地ではなく進む向きを指す
- 魚群に船べりを寄せると、船上の漁師が自動で一本釣りを始める。船体に沿った横長の漁獲範囲なので、群れを突っ切るより**並走**したほうが獲れる
- 一定本数ごとにゲームが止まり、6系統からランダムな3つが提示される。1つ選んで再開
- 180秒経過で終了。釣った本数がそのままスコア

## 強化

| | 効果 |
|---|---|
| 漁師 | 乗組員 +3人。釣り座が埋まっていれば待機に回り、船体を強化した瞬間に乗り込む |
| 船体 | 船が伸びて最大乗船人数と漁獲範囲が増える（9t → 199t） |
| 釣り速度 | 漁師一人あたりの一本釣り頻度 |
| 機関 | 航行速度 |
| 魚群探知機 | 探知レンジ。Lv1では画面に見えている範囲とほぼ同じで、上げると画面外の反応が読める |
| 集魚 | 魚群が船べりへ寄ってくる距離 |

海底に沈んだ宝箱を拾うと、ランダムな強化が1〜5個まとめて入る。

## 技術

依存なしの単一HTMLファイル。ビルド不要で、`index.html` をブラウザで開けばそのまま動く。

- Canvas 2D、内部解像度 480×270 のピクセルアートを整数倍で拡大
- 画像アセットは外部ファイルを持たず、船・漁師・カツオ・宝箱・海面まですべて起動時にコードで生成している
- 魚は群れ単位で動かしつつ1匹ずつ描画する。終盤は在世7,000匹・画面内1,000匹規模で、描画は1フレーム1.3ms程度
- 自己ベストは localStorage に保存
